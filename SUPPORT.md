# Support

Language: **English** | Deutsche Version: [Docs/community/de/support.md](Docs/community/de/support.md)

Open-Git-Control uses structured GitHub forms so reports and ideas contain enough context to act on.

## Where to Ask or Report

- Bug report: use the Bug Report form when something does not work as expected.
- Feature request: use the Feature Request form for ideas, workflow improvements, and new capabilities.
- Question: use the Question form when you need help understanding current behavior.
- Documentation report: use the Documentation form when README, screenshots, setup steps, or release notes are unclear or outdated.
- Security issue: do not use public issues. Follow [SECURITY.md](SECURITY.md).

Blank issues are disabled so new issues stay structured and easier to triage.

## Good Reports Help

Please include the app version, operating system, Git version, installation method, reproduction steps, expected behavior, actual behavior, and screenshots or logs when useful.

For questions and feature requests, describe the workflow you are trying to complete. That is often more helpful than only describing a button or screen.

## Maintainer Expectations

This is an open-source project with limited maintainer time. Clear reports, small pull requests, and reproducible examples make it much easier to help.

# Code of Conduct

Language: **English** | Deutsche Version: [CODE_OF_CONDUCT.de.md](CODE_OF_CONDUCT.de.md)

Open-Git-Control should be a practical, respectful place for people to report problems, ask questions, suggest ideas, and contribute improvements.

## Expected Behavior

- Be kind, patient, and constructive.
- Assume good intent, especially when someone is new to Git, Electron, React, or open source.
- Keep discussions focused on the project and the concrete problem being solved.
- Give actionable feedback and explain tradeoffs when possible.
- Respect different experience levels, backgrounds, languages, and working styles.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeatedly derailing issues, pull requests, or reviews.
- Pressuring maintainers or contributors for unpaid work, timelines, or private support.

## Enforcement

Maintainers may edit, hide, lock, or delete comments; close issues or pull requests; block users; or report abuse to GitHub when needed. Enforcement decisions are made to keep the project safe, useful, and welcoming.

If you see behavior that violates this code of conduct, use GitHub's reporting tools or contact the maintainers through the repository's moderation channels.
